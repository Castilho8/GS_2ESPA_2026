# Água em Casa - Dynamic Programming
Recomenda o que a família pode fazer com a água que sobrou na caixa (problema da mochila com grupos).
1. Instale: `pip install jupyter matplotlib`
2. Deixe `atividades_agua.csv` na mesma pasta e abra `recomendacao_agua.ipynb` no Jupyter ou no VS Code.
3. Execute todas as células (Run All): exemplos, testes e medição de tempo.
